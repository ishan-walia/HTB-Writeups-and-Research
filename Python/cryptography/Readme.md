# cryptography
The cryptography library is a Python package used to implement modern cryptographic techniques.

It can be used for:

- 🔒 Encryption & Decryption
- 🔑 Secure Key Generation
- 🛡️ Data Protection
- #️⃣ Hashing
- ✍️ Digital Signatures
- 🔐 Public & Private Key Cryptography
- 📜 Certificates
- 🔑 Password-related cryptographic operations
