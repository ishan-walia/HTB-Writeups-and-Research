# Selenium

This directory contains my Python and Selenium-based cybersecurity automation/practical work.
The purpose of these projects is to understand how Python can be used with Selenium for web automation, browser interaction, testing, and security-related practical exercises.

# Topics Covered
- Python fundamentals for cybersecurity
- Selenium WebDriver
- Browser automation
- Finding and interacting with web elements
- XPath and CSS selectors
- Forms and input automation
- Buttons, links, and page navigation
- Screenshots and browser handling
- Automated web testing
- Basic security testing concepts
