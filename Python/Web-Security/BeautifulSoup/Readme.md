# BeautifulSoup
BeautifulSoup Python ki library hai jo HTML/XML documents ko parse karke unke elements ko easily search aur extract karne deti hai.

# Library install:
```
pip install beautifulsoup4 requests
```

- 🔎 HTML structure analyze karna
- 🔗 Links collect karna
- 📝 Forms identify karna
- 📄 Page titles/headings extract karna
- 🔍 HTML comments aur metadata inspect karna
- 🤖 Security reconnaissance ko automate karna
