## 📌 Overview

This directory acts as the central hub for practical, hands-on lab exercises and capture-the-flag (CTF) environments across industry-standard cyber platforms:

* **[🟢 HackTheBox (HTB)](./HackTheBox/)**: Real-world penetration testing boxes, DFIR Sherlocks, offensive security labs, and specialized CTF challenge modules.
* **[🔴 TryHackMe (THM)](./TryHackMe/)**: Progressive guided security rooms, multi-host network attack chains, privilege escalation labs, and CTFs.

---

## 🗂️ Lab Structure

```text
Labs/
│
├── 🟢 HackTheBox/
│   ├── 🎯 Challenges/       # Web, Crypto, Forensics, Reverse Engineering
│   ├── 🔍 Sherlocks/        # Real-world Incident Response & DFIR Investigations
│   └── 🖥️ Machines/         # Easy, Medium, Hard & Insane target machines
│
└── 🔴 TryHackMe/
    ├── 📦 Rooms/            # Guided rooms organized by difficulty (Easy / Medium / Hard)
    ├── 🌐 Networks/         # Multi-host attack chains and enterprise pivoting
    ├── 🏆 CTF-Challenges/   # Competitive & timed jeopardy-style challenges
    └── 📝 Walkthroughs/     # Step-by-step methodologies and post-exploitation notes
```
